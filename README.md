# Socialslop game assets

Public mirror of the asset trees served at `assets.socialslopgames.com`.

Browse folders below, or download individual files from GitHub.

## Layout

| Path | Game |
|------|------|
| `static/dragonstadium/` | Dragon Stadium |
| `static/dragonland/` | Dragon Land |
| `static/dragoncity/` | Dragon City (partial) |

Same paths as the live CDN, e.g.:

`static/dragonstadium/Android/4/DRG_Fire_01_EVO12.assetBundle`
→ `https://assets.socialslopgames.com/static/dragonstadium/Android/4/DRG_Fire_01_EVO12.assetBundle`

## Notes

- Preservation / community download copy. Games still load assets from the CDN in normal play.
- Large binary trees; clone may take a while (every file is under 100MB — no Git LFS required).
